# Kauprit Chatterjee — Project Portfolio

A curated overview of engineering prototypes across Earth observation, computer vision, edge systems, mobile applications, and embedded networking. Each project is described in plain English with its current scope and source availability.

> **Portfolio status:** Project summaries are published here. Full source consolidation for every project is still in progress; use only the links marked as public source or live demo below.

## Earth observation

### NISAR-PULSE
An interactive SAR concept demo that explains land subsidence, ice movement, and disaster signals through map-style visual comparisons and readable annotations. The demo uses illustrative/synthetic scenes rather than operational NISAR measurements.

- [Open the live demo](https://nisar-pulse-demo.pages.dev/)
- [Existing source repository](https://github.com/chatterjeekauprit-max/de-spaciato) — earlier public repository; the complete curated source is still being consolidated.

## Computer vision and response

### Offline Vision-X
A local-first camera vision prototype for object detection and tracking, designed to work without a cloud inference dependency.

- [Existing public repository](https://github.com/chatterjeekauprit-max/trinoyon)

### Rescue Drone Vision
An experimental aerial search-and-rescue vision workflow for reviewing imagery and surfacing candidate areas of interest. It is a prototype and is not an autonomous rescue system. Large private footage, model weights, and datasets are intentionally not included in the public source package.

- Full curated source publication is pending.

## Edge deployment and infrastructure

### Manvinex / Valrix
An experimental edge-deployment platform concept connecting a coordinating service with edge-device software. The project explores packaging, device workflows, integrity checks, and execution status reporting. It is not presented as a production security service.

- [Existing public package repository](https://github.com/chatterjeekauprit-max/msvinex-enterprice)
- Full reviewed source publication is pending.

### Virtual Dual-Mesh Router
A Raspberry Pi and ESP32 networking experiment exploring a dual-mesh bridge and device connectivity.

## Notes

- These projects have different levels of completeness; project READMEs document what is implemented and what remains experimental.
- No project is represented as clinically validated, operationally certified, or powered by a newly trained model unless its repository provides evidence for that claim.
